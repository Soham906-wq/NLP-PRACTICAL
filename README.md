📘 NLP Tokenization, Stemming, and Lemmatization using NLTK

This project demonstrates various Natural Language Processing (NLP) preprocessing techniques using the Python library NLTK.

🚀 Features
Multiple tokenization techniques:
Whitespace Tokenization
Punctuation-based Tokenization
Treebank Tokenization
Tweet Tokenization
Multi-Word Expression (MWE) Tokenization
Stemming:
Porter Stemmer
Snowball Stemmer
Lemmatization:
WordNet Lemmatizer 

🧠 Technologies Used
Python
NLTK (Natural Language Toolkit)
📂 Project Structure
